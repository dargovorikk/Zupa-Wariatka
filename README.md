# Zupa Wariatka

Wesoła gra dla dzieci: przesuwaj garnek i łap warzywa i owoce. Uważaj na skarpety i buty!

- Działa w przeglądarce, na Androidzie i iPhonie (można dodać do ekranu głównego).
- Działa offline po pierwszym uruchomieniu.
- Języki: polski, ukraiński, angielski.

Więcej przepisów roślinnych i bezglutenowych: https://weganpolska.pl
https://dargovorikk.github.io/Zupa-Wariatka/
